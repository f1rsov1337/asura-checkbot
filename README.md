# 📚 Asura Scans → Telegram

Бот присылает в Telegram сообщение, когда у отслеживаемой манхвы на Asura Scans выходит новая глава.
Работает бесплатно на GitHub Actions, компьютер можно не включать.

## Настройка (~5 минут)

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. **Залей этот код на GitHub** в новый репозиторий (лучше **публичный**, см. ниже).
3. **Settings → Secrets and variables → Actions → New repository secret:**
   - `TELEGRAM_TOKEN`: токен от BotFather
4. **Узнай свой chat id.** Напиши боту `/start`, потом во вкладке **Actions** открой *Check new chapters* → **Run workflow**.
   Бот ответит: «Твой chat id: 123456789».
5. Добавь второй секрет `TELEGRAM_CHAT_ID` с этим числом.
6. Готово. Пиши боту `/add solo leveling` или кидай ссылку на тайтл.

## Команды

| Команда | Что делает |
|---|---|
| `/add <ссылка или название>` | отслеживать тайтл (если найдётся несколько, бот покажет кнопки) |
| просто ссылка на тайтл | то же, что `/add` |
| `/remove` | убрать тайтл (кнопками) |
| `/list` | список с последними главами |
| `/check` | проверить прямо сейчас |

## Что нужно знать

- **Бот отвечает не сразу.** Скрипт запускается по расписанию примерно раз в 15 минут (GitHub иногда задерживает запуск), поэтому и на команды бот отвечает с такой же задержкой.
- **Публичный или приватный репозиторий.** Для публичных репозиториев Actions бесплатны без ограничений. У приватных лимит 2000 минут в месяц, а запуск каждые 15 минут съедает около 2900. Если нужен приватный, поменяй в [`check.yml`](.github/workflows/check.yml) `*/15` на `*/30`.
  В `state.json` хранится только список тайтлов. Токен и chat id лежат в секретах и никуда не попадают.
- Если сайт долго не открывается (около 3 часов подряд), бот один раз предупредит.
- Если Asura снова сменит домен, поправь `BASE_URL` в [`bot.py`](bot.py).

## Запуск локально (по желанию)

```powershell
$env:TELEGRAM_TOKEN="..."; $env:TELEGRAM_CHAT_ID="..."
python bot.py --loop   # отвечает на команды сразу, проверяет главы раз в 15 минут
```
